# Graphs

A graph is a non-linear data structure consisting of vertices (or nodes) and edges that connect these vertices.

## Types of Graphs

1. **Directed Graph (Digraph)**
    - Edges have direction
    - Represented by arrows pointing from one vertex to another

2. **Undirected Graph**
    - Edges have no direction
    - Connections are two-way

3. **Weighted Graph**
    - Edges have associated costs or weights
    - Common in network and routing problems

4. **Cyclic Graph**
    - Contains at least one cycle
    - A path that starts and ends at the same vertex

5. **Acyclic Graph**
    - Contains no cycles
    - Trees are examples of acyclic graphs

## Properties

- **Degree**: Number of edges connected to a vertex
- **Path**: Sequence of vertices connected by edges
- **Connected**: Every vertex can be reached from any other vertex
- **Complete**: Every vertex is connected to every other vertex
- **Sparse**: Few edges compared to possible maximum edges
- **Dense**: Many edges close to maximum possible edges

## Common Applications

- Social Networks
- Road Networks
- Computer Networks
- Circuit Design
- Dependency Management
